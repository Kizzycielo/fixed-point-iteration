Mathematical Discussion

The Fixed-Point Iteration Method is used to solve equations in the form:

x = g(x)

Starting from an initial guess x₀, the next approximation is computed using:

xₙ₊₁ = g(xₙ)

The process repeats until the error becomes very small. If the method converges, the approximations approach the actual root.

Worked Example 1

Solve:

x = cos(x)

Initial Guess:

x₀ = 0.5

Step-by-Step Solution

Iteration Formula Result
1 x₁ = cos(0.5) 0.877583
2 x₂ = cos(0.877583) 0.639012
3 x₃ = cos(0.639012) 0.802685
4 x₄ = cos(0.802685) 0.694778
5 x₅ = cos(0.694778) 0.768196

The values converge to:

x ≈ 0.739085


Worked Example 2

Solve:

x = √(x + 2)

Initial Guess:

x₀ = 1

Step-by-Step Solution

Iteration Formula Result
1 x₁ = √(1 + 2) 1.732051
2 x₂ = √(1.732051 + 2) 1.931852
3 x₃ = √(1.931852 + 2) 1.982889
4 x₄ = √(1.982889 + 2) 1.995718
5 x₅ = √(1.995718 + 2) 1.998929

The values converge to:

x ≈ 2
